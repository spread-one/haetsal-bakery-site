# 햇살 베이커리 소개 사이트 (합성 테스트 저장소)

> 이 저장소는 Agreed 프로젝트의 GitHub 연동(클론 및 코드 탐색)을 검증하기 위한 **완전 합성 테스트 저장소**입니다.
> 실제 고객·실제 계약·실제 매장과 무관합니다. 실제 개인정보·연락처·사진 저작물을 사용하지 않습니다.

Agreed의 합성 프로젝트 **'[합성] 햇살 베이커리 소개 사이트'** (`be/scenarios/bakery.json`)에 대응하는 정적 소개 사이트입니다. 해당 시나리오 파일은 Agreed 쪽 경로이며 이 저장소에는 포함하지 않습니다.

## 계약 범위 및 현재 구현 범위 (합성)

- `index.html`: 가상 빵집 소개, 메뉴·매장 안내 링크
- `menu.html`: 빵 6종의 이름·설명·예시 가격, 직접 제작한 SVG 일러스트
- `store.html`: 가상 주소, 요일별 영업시간 표, 가상 연락처, 정적 위치 도식
- 공통 헤더·푸터·내비게이션과 반응형 공통 CSS
- 한국어 문서(`lang="ko"`), viewport, 시맨틱 영역, 이미지 대체 텍스트, 표 헤더, 현재 페이지 표시, 키보드 초점 스타일 및 본문 바로가기
- **카드 결제/온라인 주문/회원가입은 계약 범위 밖이며 구현되어 있지 않음**
- 장바구니·로그인 역시 범위 밖이며 구현되어 있지 않습니다. 관련 UI·처리 코드·서드파티 SDK가 없습니다. 결제 미구현 상태는 연동 분석 테스트 시나리오의 전제입니다.

HTML/CSS만 사용합니다. 빌드 도구·프레임워크·JavaScript·외부 의존성·외부 폰트·외부 지도 임베드·백엔드는 없습니다.

## 로컬 실행

저장소 루트에서 Python 3 정적 서버를 실행합니다. 패키지 설치나 빌드는 필요 없습니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 다음 주소를 엽니다.

- 홈: <http://127.0.0.1:8000/index.html>
- 메뉴: <http://127.0.0.1:8000/menu.html>
- 매장: <http://127.0.0.1:8000/store.html>

서버 종료는 `Ctrl+C`입니다. HTML 파일을 직접 열어도 상대 경로 링크와 이미지가 동작합니다.

## 합성 데이터와 일러스트

메뉴·가격·주소·영업시간은 모두 가상 예시입니다. 전화 `010-0000-0000`과 이메일 `hello@example.com`은 실제 문의 창구가 아니며, 사이트에는 연락 실행 링크를 두지 않았습니다. 모든 SVG는 이 저장소를 위해 직접 작성한 도형 기반 일러스트입니다. 위치 도식은 실제 지도나 길 안내가 아닙니다.

## 확인 방법 및 초기 검증 결과

- 세 페이지가 열리는지, 상단 내비게이션과 홈의 두 안내 링크로 이동되는지 확인합니다.
- 개발자 도구에서 320·375·768·1440px 폭으로 전환하여 가로 넘침, 글자·이미지 겹침, 표와 메뉴 카드 배치를 확인합니다.
- `Tab`으로 본문 바로가기와 링크에 접근하고 `Enter`로 이동을 확인합니다.
- 메뉴 6종의 이름·설명·가격, 매장 영업시간·가상 연락처, 모든 페이지의 합성 고지를 확인합니다.

초기 구현은 별도 임시 환경의 Playwright/Chromium으로 위 네 폭에서 세 페이지(총 12개 조합)를 검증했습니다. HTTP 200, 로컬 링크 및 이미지 로딩, 내비게이션 클릭, 가로 넘침 없음, 본문 바로가기 초점 이동을 확인했습니다. 375·1440px 전체 페이지 스크린샷도 생성했습니다. 이 검증 도구는 사이트의 의존성이 아니며 저장소에 포함하지 않습니다.
